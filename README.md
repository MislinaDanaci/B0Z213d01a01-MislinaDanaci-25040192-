# Uyku Asistanı (Sleep Assistant)

Uyku Asistanı, geceleri **"Bir bölüm daha dizi/film izlesem sabah uyanabilir miyim?"** ikileminde kalan kullanıcılar için tasarlanmış, terminal tabanlı bir zaman ve uyku yönetimi aracıdır. 

Kullanıcının mevcut saatini, sabah uyanma hedefini, izleyeceği içeriğin süresini ve kişisel uyku ihtiyacını baz alarak; uyku düzeninin bozulup bozulmayacağını matematiksel olarak analiz eder.

##  Özellikler

- **Dinamik Uyku Analizi:** Kullanıcının minimum uyku ihtiyacına göre özel hesaplama yapar.
- **Esnek Zaman Algoritması:** Gece yarısı öncesi ve sonrası saat girişlerini (0-23 arası) sorunsuz işler.
- **Ondalıklı Saat Desteği:** Buçuklu saatleri (Örn: 22.5) algılayarak hassas hesaplama sunar.
- **Anında Geri Bildirim:** Kullanıcıyı uykusuz kalma riskine karşı net bir şekilde uyarır.

##  Kullanılan Teknolojiler

- **Dil:** Python 
- **Geliştirme Ortamı:** IDLE
